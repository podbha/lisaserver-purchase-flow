# 丽萨主机购买教程：从注册、选套餐到优惠码付款的完整下单流程

丽萨主机购买真正容易出错的地方，不是“怎么付款”，而是**先选错线路和 IP 类型，付款之后才发现用途对不上**。

丽萨主机（LisaHost）目前的产品覆盖美国、香港、日本、新加坡、台湾、英国、韩国、德国、越南等地区，购买中心里又进一步分成 AS9929、AS4837、CN2 GIA、CMI、住宅 ISP、VDS 等不同线路或 IP 类型。官网当前还在持续上新产品，例如德国法兰克福双栈线路，并对部分节点发布网络维护公告。

所以这篇丽萨主机购买教程不从品牌故事讲起，而是直接解决几个购买前最实际的问题：

你应该先选什么产品？优惠码在哪里填？月付和年付怎么选？哪些产品支持 48 小时退款？哪些特殊产品只退网站余额？付款完成后又该去哪里找服务器信息？

下面按真正下单的顺序说。

## 丽萨主机购买前，先把三个选择弄清楚

### 1. 先决定国家或地区，再决定线路

同样是 VPS，丽萨主机不同地区的产品用途差异很大。

美国系列里，当前可以看到 AS9929 双 ISP 住宅 IP、AS4837 双 ISP 住宅 IP、CN2 GIA 高防、纽约和芝加哥住宅 IP，以及家庭宽带静态住宅 VDS。香港则有三网 CMI/CU2/CN2、iCable 和 HGC 三类明显不同的线路。日本又分成普通原生 IP、ISP 住宅 VDS、IIJ 双 ISP 住宅 VDS 等产品。官方购买中心当前就是按照这些产品系列拆开的。

可以把选择逻辑简单理解成：

| 你的主要需求 | 优先关注 |
| --- | --- |
| 美国地区 IP、跨境业务、海外平台 | 美国 9929 / 4837 / 住宅 IP 系列 |
| 需要大陆访问线路优化 | 香港 CMI/CU2/CN2、美国 CN2 GIA、部分三网优化系列 |
| 香港本地 IP 与港区服务 | 香港 iCable / HGC |
| 日本本地 IP | 日本原生 IP / 日本 ISP / 日本 IIJ |
| 韩国地区服务 | 韩国双 ISP 住宅 IP |
| 新加坡地区 IP | 新加坡原生 IP |
| 德国地区 IP | 德国双栈原生 IP或德国双 ISP 住宅 VDS |
| 越南本地业务 | 越南双 ISP 住宅 IP |
| 需要大量带宽或不想算流量 | 对应系列的不限流量版本 |

这里有个容易忽略的问题：**“原生 IP”与“住宅 ISP IP”不是同一个概念，“线路优化”也不等于“住宅 IP”。**

例如美国 CERA CN2 GIA 产品强调的是 CN2 GIA 网络和高防能力；美国 9929、4837系列则同时突出双 ISP 住宅 IP；日本 ISP、IIJ，以及美国静态住宅 VDS，则属于更明确的家庭宽带或 ISP 属性产品。

### 2. 再看流量，而不是只看 CPU

很多新手会先盯着“几核、几 GB 内存”，但 VPS 实际用途经常是网络流量先碰到瓶颈。

以目前美国 9929 一期为例，精简版是 1 核、1GB、10GB NVMe、50Mbps、1000GB/月，基础版升到 20GB、60Mbps、2000GB/月，进阶版是 2 核 2GB、40GB、80Mbps、4000GB/月，豪华版则是 4 核 4GB、80GB、100Mbps、8000GB/月；另外还有不限流量 Lite 和 Pro。

这就是为什么“更贵的套餐”不一定只是 CPU 和内存更多。不限流量版本往往牺牲了一部分带宽配置，换取流量不设月度上限。

### 3. 最后才决定月付还是年付

月付的优势是试错成本低。年付的优势则是单位月成本明显下降。

目前公开的年付特价系列覆盖美国、香港、日本、新加坡、台湾、英国、韩国、越南、日本 ISP VDS、德国双 ISP VDS，以及美国静态住宅 VDS 等多条产品线。近期整理显示，年付特价里存在 199 元/年的美国 9929 非原生 IP、399 元/年的美国 4837 双 ISP、499 元/年的美国 9929 双 ISP和日本原生 IP、566 元/年的香港 CMI，以及 699～899 元/年不等的多个住宅 IP/VDS 产品。

但年付并不自动等于适合你。第一次使用某个地区或线路，先月付测试，通常比直接一次付一年更容易控制风险。

注册时建议使用自己长期能收到邮件的地址。VPS 订单、服务信息、工单通知等，都不适合绑定一个以后不用的临时邮箱。

### 第二步：进入“购买产品”，先选系列

登录后进入产品中心。

这里不要一上来看到“价格最低”的机器就下单。先确认：

**地区 → IP 类型 → 网络线路 → 流量 → CPU/内存。**

例如：

想要美国双 ISP 住宅 IP，可以看美国 9929 或 4837；想要香港三网低延迟线路，则看香港 CMI；想要香港本地住宅 IP，就去看 iCable 或 HGC。官方当前购买页面就是这样拆分产品的。

### 第三步：进入具体套餐，核对配置

到了产品页面，不要只看第一行价格。

至少核对下面几个字段：

* CPU 核数
* 内存
* SSD/NVMe 容量
* 带宽
* 月流量或不限流量
* IPv4 数量
* 是否支持 Windows
* 自动开通还是人工开通
* 退款规则

例如，美国静态住宅 IP VDS 页面明确写有部分产品属于特殊产品，**仅退网站余额**；日本 ISP VDS、台湾 VDS 等页面也有类似说明。

这和普通 VPS 页面上的“48 小时不满意，无条件退款”不是一回事。

### 第四步：加入购物车并选择周期

选好套餐后进入购物车。

常见周期包括月付、季付、半年、年付，购物车页面本身也会展示这些周期选项。

建议新用户这么选：

第一次买、线路不熟：月付。

已经确认地区和线路没问题：再考虑年付。

长期稳定业务：可以进一步比较年付特价产品。

不要因为“年付折算下来便宜”就直接锁两年或更久。真正需要关注的是这台机器是否适合你的业务，而不是月均数字看起来有多漂亮。

### 第五步：输入优惠码

目前丽萨主机官方公告频道仍在发布：

`TS-CBP205DQJE`

公告中明确标注为**全场永久 9 折优惠码**，近期的新产品和美国 9929、4837等产品公告也继续使用这一优惠码。

把优惠码输入订单页面后，记得点击“验证”，确认页面真的出现优惠金额，再继续付款。

不要只输入不验证。

因为“输入框里有一串代码”和“订单已经实际减免”是两回事。

近期第三方购买教程还记录了循环折扣以及不同长期周期的额外优惠，但这部分不同产品和不同时间可能存在调整，因此结算页实际显示金额应作为最终金额依据。

### 第六步：付款

近期公开的购买教程和实操文章均记录丽萨主机支持支付宝付款；一些资料同时提到微信支付和信用卡。由于支付通道可能根据账户、产品和时间变化，实际付款时应以购物车和结账页面显示的方式为准。

付款完成后，常规 VPS 产品通常会自动开通。官方当前多个产品页直接标明“自动开通，即时交付”。

## 不知道怎么选？用“需求 → 产品”最省事

普通 VPS 自动开通后，下一步就是进入用户中心查看服务器信息。
